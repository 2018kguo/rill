## 安装步骤

1. 首先安装依赖：`npm install streamdown`。
2. 然后在组件中引入**Streamdown**组件。
3. 最后，运行 `npm run dev` 启动开发服务器（默认端口为 **3000**）。

> 注意：如果使用 **Next.js**，请确保版本不低于 14。
