# rill-cmark

A fork of [pulldown-cmark](https://github.com/pulldown-cmark/pulldown-cmark) 0.13.4 (MIT,
see `LICENSE`) whose grammar matches micromark as remark parses Markdown for Streamdown:
remark-gfm, remark-math with `singleDollarTextMath: false`, and remark-cjk-friendly
(including its GFM strikethrough). Every change from upstream carries a `rill:` comment.

Among the changes:

- CJK-friendly flanking for `*`, `_` and `~`; attention and strikethrough resolve in
  micromark's order (first use, then each span's interior in isolation), at most two
  delimiters per step, with the rule of 3 on remaining run sizes.
- The GFM literal autolink tokenizer (micromark-extension-gfm-autolink-literal), found in
  the inline pass so code spans and links keep their precedence.
- `$$` math (flow and text), definitions as events, and micromark's interrupt rules for
  list items, tables, setext headings and lazy lines.
- GFM tables: any paragraph line can head a table, micromark's delimiter-cell grammar,
  and the row rules that end a table.

`src/unicode_tables.rs` is generated by `gen-unicode-tables.mjs` from the Unicode data
Node.js ships, so classifications match JavaScript's `\p{P}`, `\p{S}` and `\s`.
